# CYPHIX_ONE_PAGER

The investor one-pager: the landing page ([cyphix-landing.vercel.app](https://cyphix-landing.vercel.app))
set on one A4 page, as a PDF to attach to an intro e-mail.

**The file to send: [`Cyphix-One-Pager.pdf`](Cyphix-One-Pager.pdf)** (one page, 1.5 MB, links clickable).

**Kept off, on purpose** (same rules as the site, see `../LANDING PAGE/PRODUCT.md`):
- no amount for the round;
- no partner or medical-centre names;
- competitors named by category, never by brand;
- the deck's 2026 market figures ($4.97B / $3.03B). The page keeps the site's $4.53B / $2.76B.

**Data, never a reading.** The tablet's screen is the site's illustrative recording, without
the axis and rhythm verdicts ("Normal axis", "Regular"), the normal-range sector and the red ST
marks. The site's hero still shows them.

## Files

```
CYPHIX_ONE_PAGER/
├── Cyphix-One-Pager.pdf   ← the deliverable (generated)
├── preview.jpg            ← the sheet as an image (generated)
├── one-pager.html         ← the page, written by hand; opens in a browser as a sheet
├── one-pager.css          ← its styles: the site's tokens on a 794 × 1123 px sheet (A4 at 96 dpi)
├── assets/                ← fonts and pictures from the landing page (generated by tools/assets.mjs)
│   ├── fonts/             ← Sora, Geist Mono (self-hosted, as on the site)
│   └── img/               ← the forearm, the tablet (frame + screen as SVG), the four watches,
│                            the portraits, the heart-hands blurred for print
└── tools/
    ├── assets.mjs         ← refreshes assets/ from ../LANDING PAGE and the live site
    └── build.mjs          ← checks the sheet, prints the PDF, writes the preview
```

## Rebuilding

Both tools borrow `puppeteer-core` from `../LANDING PAGE/node_modules` and drive the installed
Chrome (`CHROME=` overrides its path).

```bash
node tools/assets.mjs     # only when the site's pictures changed (reads the live site by default)
node tools/build.mjs      # prints Cyphix-One-Pager.pdf + preview.jpg
```

`build.mjs` refuses to print when the sheet overflows the page, a line overflows its box, or
a picture or font failed to load. It then confirms the PDF has exactly one page. Edit the
copy in `one-pager.html`; keep every claim one the site already makes.
